# VEX-NOVA

مساعد الذكاء الاصطناعي الذي يفهم العالم من حولك
تخيل مساعدًا ذكيًا يتحدث معك بالصوت، ويفهم العربية والفرنسية، ويساعدك حتى عندما يكون الإنترنت ضعيفًا.
لكن ما يميزه هو أنه مصمم خصيصًا للأشخاص الذين لا تتوفر لهم بسهولة الخدمات التعليمية والتقنية.
ما الذي سيجعله مختلفًا؟
🎙️ التواصل الصوتي: تتحدث إليه بدلًا من كتابة الأسئلة.
🌍 تعدد اللغات: العربية والفرنسية، مع إمكانية تطوير دعم لغات محلية لاحقًا.
📶 العمل في ظروف الإنترنت الضعيف: توفير بعض الوظائف دون اتصال، بحسب الإمكانات التقنية.
🧠 التعلم الذكي: يشرح المسائل العلمية وفق مستوى المستخدم.
💡 المساعدة العملية: يرشد المستخدم إلى أدوات ومصادر تساعده على تنفيذ المهام.
🔎 المعلومات الموثوقة: يوضح مصادر المعلومات، ويميّز بين الحقائق والاحتمالات.
